## Dacă tocmai pornești o instalare

O ordine rezonabilă pentru prima lună:

1. **Întâi oamenii.** Creează [grupurile de speologie](../features/people-and-clubs.md),
   adaugă lista de speologi (inclusiv persoane fără cont) și invită-i pe cei care se vor
   autentifica, de la [Administrare → Conturi](../admin/accounts.md).
2. **Hotărăște-ți grupurile de permisiuni** înainte să ai date de stricat.
   Vezi [Permisiunile explicate](../admin/permissions.md).
3. **Pregătește vocabularele** de care știi că ai nevoie — tipuri de peșteri, tipuri de
   obiecte, tipuri de documente, scopuri de tură. Vezi
   [Vocabulare](../admin/vocabularies.md).
4. **Introdu registrul.** De obicei prin [importul fișierelor GPS](import-a-gps-file.md)
   mai degrabă decât prin tastare, apoi corectând.
5. **Apoi arhiva.** [Dulapuri](../features/documents-and-cabinets.md) și
   [încărcări](../features/uploads.md) în masă.
6. **Apoi topografiile, relieful și 3D-ul** — sunt părțile care se răsplătesc cel mai mult dacă
   restul este deja pe loc.

Turele și evenimentele pot începe din prima zi; nu depind de nimic altceva.
