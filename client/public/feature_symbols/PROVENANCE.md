# Feature symbol icons — provenance

The 19 PNG icons in this directory render surface-feature symbols on the map
(sinkhole, spring, pitch, chimney, fracture line, etc.).

## Origin

These symbols were carried over from earlier SilexGIS versions (the v1 PHP
application, in use by the Silex Brașov speleo club since ~2014). They are part of
the club's own cartographic symbol set for speleological surface features.
